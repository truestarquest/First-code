# Conceptual Premium E-Commerce Landing Page

Концептуальний редизайн та інтерактивний макет для преміального онлайн-магазину. Проєкт створено як демонстрацію сучасного UI/UX дизайну, високої швидкості завантаження та плавної інтерактивності без використання важких сторонніх бібліотек.

## 🚀 Особливості проєкту

* **Pure Performance:** Написано на чистому HTML, CSS та JavaScript. Жодних фреймворків — максимальна швидкість та оптимізація.
* **Premium UI/UX:** Сучасна геометрія інтерфейсу, мінімалістичний стиль та акцентні елементи (фірмовий геометричний трикутник).
* **Dynamic Theme Toggle:** Повноцінна підтримка темної (Dark) та світлової (Light) тем із плавними переходами, що адаптуються під уподобання користувача через CSS-змінні.
* **Bilingual Support:** Реалізовано інтерактивне перемикання мов (Мультимовність) на клієнтській стороні.
* **Social Commerce Integration:** Продумане інтерактивне вікно швидкого замовлення з прямою інтеграцією та переходом на Instagram бренду.
* **Responsive Design:** Повна адаптивність під мобільні пристрої, планшети та десктопи.

## 🛠 Технологічний стек

* HTML5 (Семантична верстка)
* CSS3 (Кастомні змінні, Flexbox, Grid, CSS Transitions)
* Vanilla JavaScript (Управління станом тем, локалізація, інтерактивні попапи)
